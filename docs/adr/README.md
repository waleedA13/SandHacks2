# Architecture Decision Records

We record significant technical decisions as ADRs, following [Michael Nygard's format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

## How to add one

1. Copy [`template.md`](template.md) to `NNNN-short-title.md`, using the next number.
2. Fill it in and open a PR. The decision is accepted when the PR merges.
3. Never edit an accepted ADR's decision. Write a new ADR that supersedes it and update the old one's status.
